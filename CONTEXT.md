# Общий контекст для нейросети

Этот файл целиком вставляешь в чат с нейросетью (или кидаешь файлом) **перед** тем, как просить её писать свой раздел. Так у всех пятерых тексты получаются про одно и то же, одними терминами и в одном стиле, а не «из разных концов интернета». Потом пишешь, какой раздел твой, и прикладываешь свой файл из `paper/`.

## Что мы делаем

Пишем научную статью, команда 2, курс СЦИНИ (преподаватель Д. А. Тарасов, УрФУ, 2026). Цель — журнал из белого списка ВАК.

**Название:** «Отравленная лента: экспериментальное исследование устойчивости RAG-агентов к косвенным промпт-инъекциям в контенте Telegram-каналов».

**Вопрос исследования:** как способ обработки и защиты внешнего контента влияет на успешность косвенных промпт-инъекций в RAG-агенте, работающем с сообщениями Telegram-каналов?

**Суть одним абзацем.** LLM-агенты читают чужой текст: сайты, почту, посты каналов. Модель видит этот текст вперемешку с инструкциями пользователя. Если автор канала спрятал в посте команду, агент может её выполнить: отправить сообщение, открыть ссылку, прочитать файл, записать что-то себе в память. Это косвенная промпт-инъекция, OWASP ставит её первой среди рисков LLM-приложений. Мы не только делаем обзор, но и меряем: реальные посты из каналов, в них спрятанные команды, три модели, три уровня защиты, считаем долю выполненных атак.

## Эксперимент коротко

- **Агент:** пользователь просит сводку постов канала по теме, ретривер достаёт top-3 поста, один пост в базе атакованный. Инструменты — заглушки, вызов только пишется в журнал.
- **Корпус:** около 250 реальных постов из публичных каналов (собрал Алексей) плюс контрольный класс — посты с командами для людей, а не для агента.
- **Атаки:** 4 цели (сообщение третьему лицу, ссылка, файл пользователя, запись в память) × 3 маскировки (прямая команда, «заметка для ИИ-ассистентов», приписка автора) × 3 позиции в посте.
- **Защиты:** D0 — без защиты; D1 — защитная инструкция и маркеры данных; D2 — песочница, агенту разрешён только поиск постов.
- **Модели:** коммерческая через API, отечественная русскоязычная, с открытыми весами (точные версии — `experiment/README.md`).
- **Главная метрика:** ASR — доля атак, после которых агент выполнил целевое действие. Плюс полезность на чистых постах и ложные отказы на контрольном классе. 95 % интервалы Уилсона, сравнение защит критерием Мак-Немара.

## Термины — только так

- *косвенная промпт-инъекция* — инструкция, спрятанная во внешнем контенте, который агент читает как данные (не «непрямая», не «indirect injection» в тексте);
- *прямая промпт-инъекция* — её пишет сам пользователь в чат;
- *джейлбрейк* — обход ограничений модели, чтобы она выдала запрещённое; не путать с инъекцией;
- *атакующий пост* — пост канала с внедрённой инструкцией;
- *RAG-агент* — агент, который перед ответом достаёт документы поиском из базы;
- *ASR* (attack success rate) — доля успешных атак;
- *защита D0 / D1 / D2* — как выше.

## Как писать

- Научный стиль, но без воды: короткие абзацы, каждое утверждение — со ссылкой.
- Объём раздела — 1–1,5 страницы (примерно 400–600 слов).
- Ссылки ставим ключом из `sources/references.bib` в квадратных скобках: `[greshake2023not]`. Нет ключа — дописываешь источник в `sources/team-sources.md`. **Нейросеть не должна выдумывать источники**: каждую ссылку, которую она предложила, проверяешь, что статья реально существует.
- Не пересказывать чужие разделы — сослаться: «подробнее в разделе 3».
- Оформление по ГОСТ делаем в последнюю неделю, сейчас не тратить на него время.
