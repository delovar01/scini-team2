# Отравленная лента

**Экспериментальное исследование устойчивости RAG-агентов к косвенным промпт-инъекциям в контенте Telegram-каналов**

Команда 2, курс «Современные цифровые инструменты научного исследования» (СЦИНИ), преподаватель Д. А. Тарасов, УрФУ, 2026.
Тема команды по таблице курса: «Безопасность LLM: prompt injection, guardrails, атаки на RAG».

## Вопрос исследования

> Как способ обработки и защиты внешнего контента влияет на успешность косвенных промпт-инъекций в RAG-агенте, работающем с сообщениями Telegram-каналов?

Ответ на него даёт эксперимент: доля атак, которые агент выполнил без защиты и с каждой из защит, на трёх моделях (подробно в [`experiment/README.md`](experiment/README.md)).

## Структура

```

sources/        references.bib (100 проверенных источников) и источники команды
SPRINTS.md      спринты по неделе с 13.10 по 31.10
```

## Как работаем

1. **Ветка на человека.** Имя ветки `фамилия/что-делаю` латиницей: `blinov/obzor-atak`, `fadeev/rag`, `shaikhutdinov/zashchity`, `vyalkov/threat-model`, `pavlenko/eksperiment`.
2. **Правим только свой файл** в `paper/` и свою часть в `experiment/`. Чужое — через комментарий в PR или в чат.
3. **Готово — открываешь pull request в `main`.** Степан смотрит и мержит в течение суток. Мелкие правки можно сразу, крупные — после обсуждения.
4. **Источники** в тексте ставим ключом из `sources/references.bib` в квадратных скобках: `[greshake2023not]`. Нет ключа — добавь запись в `sources/team-sources.md`, Савелий перенесёт в bib и потом переведёт всё в ГОСТ с номерами.
5. **Общие термины** (чтобы не было пяти разных «инъекций»):
   - *косвенная промпт-инъекция* — инструкция, спрятанная во внешнем контенте, который агент читает как данные;
   - *атакующий пост* — пост канала с внедрённой инструкцией;
   - *защита* — D0 без защиты, D1 защитная инструкция, D2 песочница с урезанными правами;
   - *ASR* (attack success rate) — доля атак, после которых агент выполнил целевое действие атакующего.
6. **Без git тоже можно.** Не получается — кидай текст в тему «материалы» в чате, Степан зальёт сам.
7. **Ключи API не коммитим никогда.** Они живут в `experiment/.env`, который в `.gitignore`. Шаблон — `experiment/.env.example`.
